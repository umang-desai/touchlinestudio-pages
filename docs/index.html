FAQ

Quick answers for new coaches getting started.

Does Touchline Studio work offline?

Yes. Core features work fully offline. Internet is only needed for AI drill generation.

How do I sync across devices?

Enable iCloud for Touchline Studio in iOS Settings → your Apple ID → iCloud → Apps Using iCloud.

Do you collect analytics or track usage?

No. Touchline Studio does not include analytics SDKs or tracking pixels.

How does the AI drill creator work?

You choose a model and provide your own OpenRouter API key. Only the drill parameters you enter are sent to the AI service.
